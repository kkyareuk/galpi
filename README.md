# 갈피 v0.3.0

커플링 × AU로 정리하는 개인 소설 서재와 집필·연습 웹앱.

## 주소와 접근

https://galpi-fiction-library.kkyareuk.chatgpt.site

사이트는 공개이며 ChatGPT 로그인 없이 방문할 수 있습니다. Google 로그인 전에는 이 브라우저에 원고를 저장하고, 로그인 후에는 본인 계정의 원고를 불러옵니다. 작품을 다른 사람에게 공개하는 기능은 아닙니다.

## 개발

`node preview.mjs` → http://127.0.0.1:4173

`npm ci` 후 `npm test` (테스트용 jsdom만 설치하며 배포 앱에는 포함하지 않음).

새 기능은 dev에서 작업합니다. main에는 검증한 배포 소스를 반영합니다. Android 앱이 아니므로 versionCode는 없습니다.

## v0.3.0

- 회색 작업 영역과 흰 원고 페이지, 상단 고정 서식 도구, 문서 안에서 바로 편집하는 방식. 읽기 화면의 수정 버튼으로 기존 회차 편집.
- KoPubWorld 바탕·돋움, 부분/전체 폰트, 굵게·기울임·밑줄·취소선·글자색·크기·정렬, 떨림·네온·빛 효과. 글자 크기와 행간/자간/문단 간격/여백은 숫자와 ± 버튼으로 조절. 기본 17px/행간 1.6.
- 마크다운 원문과 문서 편집 전환. 제목·강조·취소선·인용·목록·링크·구분선·코드 지원. 원시 HTML/외부 이미지/표 문법은 지원하지 않음.
- 인물 사진과 대사 블록: 시리즈당 6명, 사진 자동 축소. 인물 설정은 시리즈에 저장하고 대사 본문은 원고에 포함.
- TXT/MD 가져오기: Web Worker에서 인코딩과 줄바꿈 처리, 새 회차 추가가 기본. UTF-8/UTF-16/EUC-KR 지원. 6만 자 초과 원고는 원문 모드로 먼저 열어 초기 DOM 렌더링 지연을 줄임. 기존 회차 교체 시 확인과 실행 취소 제공.
- 시리즈 생성/수정에서 표지 이미지 업로드·교체·제거. JPG/PNG/WebP 15MB 이하, 저장 시 700px/약 165KB 이하 JPEG로 압축. 표지와 인물 사진은 원고와 함께 계정 저장/백업에 포함.
- 원작 AU 우선 표시, 생성 기본 AU 원작. 자동 예시 소설 표시 제거, 기능 중심 생성 창.
- PWA manifest/아이콘/서비스 워커 및 앱 설치 안내. HTTPS 공개 사이트에서 지원 브라우저의 앱 설치/홈 화면 추가 사용. OS에 실제 설치하는 과정은 사용자 기기에서 진행. APK/AAB나 앱스토어 배포본은 아님.
- 앱 파일만 오프라인 캐시. 개인 원고는 기존 IndexedDB 사용. Google 인증/API 데이터는 서비스 워커에 캐시하지 않음. 인터넷 복귀 시 동기화 재시도. 새 버전은 기존 창을 모두 닫은 후 적용하여 편집 중 강제 새로고침 방지.

KoPubWorld 파일 출처: https://github.com/adrinerDP/font-kopubworld (파일 변형 없이 사용). 저작권: 문화체육관광부·한국출판인회의. 배포 약관은 `dist/fonts/LICENSE-KoPub.md`에 포함하고 설정에서 링크합니다. 외부 웹폰트가 불가능한 환경에서도 앱에 포함된 KoPub 파일을 사용합니다.

- 움직임 끄기 및 OS의 reduced-motion 설정 존중.
- 선택형 AI 소설 표시: 기본 꺼짐, 시리즈 생성/수정에서 선택. 책장·작품 소개·리더와 백업에 유지.

## Firebase 설정 완료 (2026-10-14)

프로젝트: kkyareuk. PC의 기존 Firebase CLI 인증 세션으로 관리했습니다. 비공개 키나 토큰을 소스에 포함하지 않습니다.

- Google Sign-In 활성화, OAuth 표시 이름 갈피.
- 승인 도메인: 기존 firebaseapp.com / web.app 유지, galpi-fiction-library.kkyareuk.chatgpt.site, 127.0.0.1, localhost 추가.
- 기존 Firestore 기본 차단 규칙 보존. users/{uid}/galpiSeries/{seriesId} 및 chapters/{chapterId}에 해당 UID 소유자만 접근 허용.
- 실제 배포된 규칙과 로컬 파일 일치 확인. Rules API 테스트에서 본인 허용/타인 차단/익명 차단, 시리즈·회차 읽기·생성 총 12개 통과. 결과: tests/firebase-verification.json.
- 브라우저 Google OAuth 팝업을 통한 최종 로그인과 기기 간 동기화는 이 환경에서 완료 확인하지 못했습니다. 관리자 설정 성공과 실제 브라우저 로그인 성공을 구분합니다.

Firestore 규칙 재배포: `npx firebase-tools deploy --only firestore:rules --project kkyareuk --config firebase.json`. 프로젝트를 다른 앱과 공유하므로 앞으로 재배포 전 원격 규칙 변경 여부를 먼저 확인합니다.

## 저장과 한계

- 기존 v0.1 원고를 유지하는 IndexedDB v2 업그레이드. 텍스트에 HTML을 저장하지 않고 검증된 서식 범위를 별도 필드로 저장합니다.
- 회차당 최대 180,000 UTF-16 코드 단위, 서식 최대 400개. 글자 수는 Unicode code point 기준.
- 입력 600ms 후 기기 저장, 1800ms 후 클라우드 전송. 클라우드 응답을 기다리지 않고 화면 전환.
- 연습 노트는 계정별 키로 이 브라우저에 저장(최근 20개). 책갈피·읽기 위치·개인 폰트·리더 설정도 기기별입니다.
- 게스트 원고는 로그인 후 자동 이동하지 않습니다. 로그인 전 백업 → 로그인 후 가져오기로 이동합니다.
- 동일 회차의 동시 편집은 지원하지 않습니다. 클라우드와 기기 캐시는 수정 시각으로 병합합니다.
- JSON 백업 복원은 새 ID 사본을 만들며 AI 표시·폰트 선택·문장 효과도 보존합니다. 개인 폰트 파일은 별도입니다.
- 외부 웹폰트는 로드 실패 시 시스템 폰트로 대체됩니다. KoPubWorld는 앱에 포함되어 있습니다.
